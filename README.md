# ETL пројекат - Да ли победе продају дресове?
    Northern Star Shop продаје опрему за 20 клубова лиге NSL. Маркетинг тим жели да зна чија опрема се највише продаје и да ли резултати на терену утичу на продају. Ваш задатак је да направите pipeline који спаја податке продавнице и лиге и одговара на то питање бројевима.  

    Подаци долазе из четири извора:  
        - поруџбине: API, JSON, 38 страна (BASE_URL)
        - производи: CSV фајл из система продавнице (FILES_URL + 'products.csv')
        - тимови: CSV фајл од лиге (FILES_URL + 'teams.csv')
        - утакмице: Parquet фајл са платформе лиге (FILES_URL + 'matches.parquet')
## Постављање пројекта на GitHub
    - Назив репозиторијума - IT Bootcamp - Data pipeline или слично (ваш избор)
    - Структура фолдера:  

    ├── data/
    │ ├── raw/ одговори API-ја, без измена (задатак 3)
    │ └── processed/ све што pipeline уписује (задаци 10–12)
    ├── pipeline.ipynb цео pipeline, једна функција по ћелији
    └── README.md шта pipeline ради и резиме резултата  

    - Све путање у коду морају бити релативне
        - Исправно: './data/raw', 'data/processed'
        - Није исправно /Workspace/Users/...
    - Свака функција је у својој ћелији, редом као што иду задаци
        - Последња ћелија само покреће (run_pipeline(RAW_DIR, PROCESSED_DIR))
    - Пробе и исписе које користите у току рада се пре предаје бришу
        - Океј је (и пожељно) да тестирамо све у току рада, али желимо да нам финални рад буде чист.
    - Пре завршетка, "рестартујте" податке и покрените Run All, свака ћелија мора да прође без грешке
    - Задатак се предаје на Ваш GitHub налог путем отвореног Pull Request-а из неке гране у главну грану
        - Поред фајлова pipeline.ipynb (Који се добија опцијом Download as -> IPython на Databricks-у) и README.MD
        - Потребно је доставити и све генерисане фајлове од стране функције run_pipeline
            - Они представљају резултате Вашег рада
